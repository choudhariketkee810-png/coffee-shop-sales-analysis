# ☕ Coffee Shop Sales Analysis

## 📌 Project Overview

This project analyzes coffee shop sales data to identify sales trends, customer purchasing patterns, popular products, peak sales hours and store performance.

The goal is to use data analysis to generate actionable business insights that can help improve sales and operational decisions.

## 🎯 Business Questions

- How have sales trended over time?
- Which days of the week are busiest?
- What times of day have the highest sales?
- Which store locations generate the most revenue?
- Which products are sold most frequently?
- Which products generate the most revenue?
- Which product categories perform best?
- What are the peak purchasing hours?
- Which products have the highest average selling price?
- Which products contribute the most to overall revenue?

## 🛠️ Tools & Technologies

- SQL
- PostgreSQL / MySQL
- Microsoft Excel
- Power BI
- Data Cleaning
- Data Analysis
- Data Visualization

## 📊 Key Analysis

The analysis focuses on:

- Revenue trends
- Transaction volume
- Product performance
- Store performance
- Customer purchasing patterns
- Peak sales hours
- Product category performance

## 📈 Dashboard

An interactive dashboard will be created using Power BI to visualize sales performance and key business insights.
